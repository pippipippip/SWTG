Star wars the gathering fan-created magic-the-gathering set. 

Folder Structure: 
1. Raw inputs - these folders have the JSONs of card text, art files and the custom spaceship frames. 
2a. Card Output - These are produced from https://mtgcardbuilder.com/creator/ 
2b. Full Art Cards - These are not in the 2a folder because these are already print-ready
3. For Printing - I can't share these full-size, only compressed.
4. Various cards I'm in the process of experimenting/upgrading.
